\# Contract-First AI Code Generator



\## 📋 Description

A self-correcting AI code generator that uses Design by Contract principles to automatically verify code correctness before delivery.



\##  Features

\- \*\*Automated Code Generation\*\*: Uses Groq API (Llama models) to generate Python code

\- \*\*Design by Contract\*\*: Forces AI to write preconditions and postconditions (assertions)

\- \*\*Self-Correcting Loop\*\*: Automatically detects errors and feeds them back to the AI to fix

\- \*\*Sandboxed Execution\*\*: Tests code safely before delivery

\- \*\*Model Agnostic\*\*: Supports Groq, OpenAI, or local models
